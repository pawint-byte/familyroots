---
name: Exact tree identity
description: Avoid confusing same-named family trees or repeated access listings when checking permissions.
---

Use the exact tree URL/identifier before diagnosing tree ownership, claimed-profile access, or recording permissions when names are duplicated.

**Why:** Production contains distinct same-named trees and repeated collaborator records. Looking up a tree by name led to a permission conclusion that did not establish which tree the member was using.

**How to apply:** Ask for the selected tree's URL when identity is ambiguous. Keep permissions findings scoped to that specific tree; do not merge trees, transfer ownership, or change roles based on matching names or visible member counts.
